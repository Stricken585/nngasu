# Сайт вуза — дизайн проекта

## Масштаб
MVP (учебный/пет-проект): без email-верификации, без восстановления пароля, без истории семестров (только текущий семестр).

## Технологический стек
- **Backend:** NestJS (TypeScript)
- **Frontend:** React + Vite (отдельное SPA, общение с backend через REST API)
- **База данных:** PostgreSQL
- **ORM:** Prisma
- **Реал-тайм:** Socket.io / NestJS WebSocket Gateway (для личных сообщений и группового чата)
- **Админ-панель:** AdminJS (или аналог) для управления группами/дисциплинами/расписанием/пользователями
- **Запуск:** docker-compose (Postgres + backend + frontend одной командой)

## Роли пользователей
- **Студент** — роль по умолчанию при регистрации
- **Преподаватель**
- **Администратор** — назначает роли, создаёт группы/дисциплины/расписание/пользователей через AdminJS

Регистрация — самостоятельная (email/пароль). Без email-верификации. Роль после регистрации по умолчанию "студент", администратор меняет роль вручную.

## Модель данных

### Группа (Group)
- Название (например, "ИВТ-21-1")
- Без вложенной иерархии курс/специальность/факультет (для MVP)

### Дисциплина (Discipline)
- Связь многие-ко-многим: дисциплина ↔ преподаватель ↔ группа
  (преподаватель может вести несколько дисциплин у нескольких групп)

### Расписание (ScheduleEntry)
- Недельный шаблон с делением на чётную/нечётную неделю
- Фиксированные пронумерованные пары (1-я пара 9:00–10:30, 2-я — 10:40–12:10 и т.д.)
- День недели
- Дисциплина, преподаватель, группа
- Аудитория (текстовое поле)
- Тип занятия: лекция / практика / лабораторная (отдельный атрибут)

### Оценки (Grade)
- 5-балльная шкала с дробными значениями (например, 3.5, 4.6)
- Несколько оценок за семестр по каждой дисциплине (история оценок, не одна итоговая)
- Без реал-тайма — обычная загрузка при заходе на страницу

### Сообщения (Message)
- Личные сообщения преподаватель ↔ студент (в обе стороны)
- Групповой чат (преподаватель → вся группа)
- Реал-тайм (WebSocket) для обоих типов
- Только текст, без вложений (для MVP)

## Функциональность по ролям

### Студент
- Смотреть расписание своей группы
- Смотреть свои оценки по дисциплинам
- Писать преподавателю (личные сообщения)
- Участвовать в групповом чате

### Преподаватель
- Смотреть своё расписание (свои дисциплины и группы)
- Ставить оценки студентам
- Писать студентам лично
- Писать в групповой чат (всей группе)

### Администратор
- Управление группами, дисциплинами, расписанием и пользователями через AdminJS
